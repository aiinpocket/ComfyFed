# ComfyFed

[English version →](README.en.md)

### 這是什麼

ComfyFed 就是把一群朋友的顯卡接在一起，變成一個小小的「算圖聯邦」：誰的顯卡有空，就幫忙跑誰送出的工作。你不用自己有一張很猛的顯卡，也不用懂 ComfyUI 怎麼裝、怎麼接節點——打開瀏覽器、選一支範本、改幾個字，剩下的事聯邦裡的機器會自動處理，圖或影片跑完直接在網頁上看、下載。

整個圈子是**熟人邀請制**：只有你信任的朋友可以加入，出圖的人跟出算力的人互相看得到誰做了什麼，不是一個對外開放、什麼人都能連的公開服務。

### 你可以用它做什麼

打開內建的「工作流編輯器」，左側就有 10 支現成範本可以直接用，每一支的畫布上都貼了紅色便條紙，清楚標出「只要改這裡」，就算完全不會寫程式、沒摸過 ComfyUI 也能照著做出成品：

- **武俠文生圖** — 打字描述一個畫面，生出一張武俠風格的圖
- **角色立繪** — 同一套流程的直式版，專門生一張角色的定裝照
- **參考圖生影片** — 給一張照片，讓照片裡的人「動起來」，還自帶聲音
- **首尾幀生影片** — 給第一格畫面、最後一格畫面，中間的動作自動補出來
- **多影片串接** — 把兩段影片接成一段，畫面聲音都接好
- **圖片開場影片** — 一張圖先當片頭卡幾秒，接著播影片
- **影片截段** — 從一段影片裡剪出想要的片段
- **圖片放大** — 一張小圖放大成高解析度
- **圖生提示詞** — 上傳一張參考圖，自動幫你寫出好用的英文提示詞
- **文字生提示詞** — 貼一段中文想法，自動整理成好用的英文提示詞

每支範本點開就是複製一份到你自己的畫布上，範本本身不會被你改壞；改完按下「Run」，工作就送進聯邦排隊，跑完的結果和紀錄都會出現在主控台的「工作」頁。

### 兩種架法

**A. 自己的電腦或 VM**：適合家裡、公司有一台常開機的機器（不用多強，Windows／Linux 都可以）。裝一次伺服器、開放一個大家連得到的網址（家用 DDNS 或固定 IP 都行），朋友的顯卡就能連進來幫忙。細節與指令見〈[自架技術指南](docs/SELF-HOSTING.zh.md)〉。

**B. Cloudflare 雲端版**：不想顧一台 24 小時開機的機器、不想搞 DDNS、不用開任何連接埠——把專案接到你自己的 Cloudflare 帳號（有免費額度），部署完就有一個網址可以用。細節見〈[雲端版指南](cloud/README.md)〉，第一次架設大致是：

```bash
cd cloud && npm install && npx wrangler login
```

兩種架法背後是**同一套聯邦協議、同一支 agent**，差別只在伺服器跑在哪裡；朋友的顯卡要接進來，兩種都是同一個步驟。

### 出算力的人

如果你有一張顯卡想借給朋友圈用，在你的機器上裝一個叫 `comfyfed-agent` 的小程式，跟平台註冊之後就會開始接工作、幫忙算圖。你的機器只會**主動連出去**找平台，不需要對外開任何連接埠，藏在家用網路 NAT 後面也完全沒問題。想停下來就在視窗按 `Ctrl-C`，它會先把手上的工作收乾淨才關掉，不會留下爛攤子。

每個工作跑完，你（worker）跟平台會**各自簽名**產生一張收據，記錄這次貢獻了多少算力——雙方都簽過的紀錄誰也不能片面竄改，貢獻多少一目了然，Reports 頁看得到排行榜。

成員之間也可以直接互傳模型檔，不用每台機器都自己去外面重抓一次——新加入一台機器，缺的模型只要圈子裡有人在線分享就能補齊，速度更快也省流量。

### 安全與信任

ComfyFed 從設計上就是給「認識的人」用的，不是公開服務：

- **邀請制**：只有平台管理員發出的一次性註冊連結才能加入，用過即失效
- **節點白名單**：worker 可以自己設定只跑哪些種類的 ComfyUI 節點，防止別人送來的工作流在你的機器上亂執行
- **雙簽收據**：貢獻算力的紀錄由雙方簽名，可稽核、不能單方偽造
- **全程簽章**：每一次連線、每一個 API 呼叫都經過密碼學簽章驗證，不是明碼裸奔
- **多使用者帳號**：管理員可以幫圈子裡的每個人開自己的帳號，大家只看得到自己送出的工作與作品，管理員才看得到全體總覽與分帳
